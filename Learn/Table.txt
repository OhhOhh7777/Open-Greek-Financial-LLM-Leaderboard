Explain Table.JS

Component Overview
    Defines a sophisticated data table component for the Open Greek Financial LLM Leaderboard. 
    It's built with React and Material UI, providing an interactive and performant way to display model comparison data.

Main Components
    1. LeaderboardTable (Default Export)
        The primary component that renders the entire table with:

        1. Virtualized row rendering for performance
        2. Sorting capabilities
        3. Sticky headers and pinned rows
        4. Custom styling based on themes
        5. Responsive design

    2. TableSkeleton (Named Export)
        Displays loading placeholders when data is being fetched, creating a visual outline of the table.

    3. Supporting Components
        A. TableControls: Manages display options like row size, score format, etc.
        B. NoResultsFound: Shows when filters return no matching models

    Key Features: 
        1. Virtualized Rendering: Only renders visible rows using @tanstack/react-virtual
        2. Pinned Models: Keeps selected models at the top when scrolling
        3. Dynamic Sorting: Allows sorting by clicking column headers
        Row Size Control: Adjusts row density based on user preference
        4. Column Management: Shows/hides columns through ColumnSelector
        5. Loading States: Shows skeleton UI during data loading
        6. Empty States: Displays friendly message when no results found
    
    Technical Highlights
        1. Implements optimized rendering with React hooks (useMemo, useCallback)
        2. Uses MUI theming for consistent styling
        3. Handles advanced table behaviors like sticky headers and conditional styling
        4. Supports accessibility through proper semantics
        5. Implements custom scrollbars with theme-aware styling
